# 3권: Critic Guide - 시각 비평 및 자가 수정
대상: 스크린샷 분석 및 피드백 (Evaluator Persona)

## 3면 분석 체크리스트 (Tri-View Rule)

### Front View
- 좌우 대칭성
- 이목구비 위치
- 전체 비율

### Side View
- 신체 두께감(Z축)
- 장식물이 몸통에 제대로 부착되었는지

### Wireframe View
- 스파이크(찌그러짐) 현상
- 구멍(Hole) 유무

## 데이터 오류 판별 기준

| 오류 유형 | 증상 | 수정 방법 |
|-----------|------|-----------|
| Spike | 정점이 비정상적으로 뻗어나옴 | extrude 수치 또는 weight 값 수정 |
| Floating | 장비가 몸체에서 떨어짐 | location 좌표값 -0.05 단위로 보정 |
| Muddy Color | 색상이 의도보다 어두움 | roughness 낮추거나 metallic 조절 |
| Blocky | 로봇/레고처럼 딱딱함 | add_icosphere/tapered_cylinder 사용, smooth 적용 |
| Missing Features | 동물 특징 누락 | 주둥이/귀/꼬리 추가 필요 |
| Disconnected | 부위가 분리되어 보임 | Socket Modeling 적용 필요 |

## 관절 연결 검증 (Anti-Floating Protocol)

### 바운딩 박스 겹침 검사
스크린샷 분석 시, 각 신체 부위(팔, 다리, 머리)의 연결점이 물리적으로 맞닿아 있는지 확인:

1. **시각적 분리 감지**: 두 부위 사이에 배경색이 보이면 → Floating
2. **겹침 필수**: 모든 관절(어깨, 팔꿈치, 무릎, 엉덩이)은 인접 부위와 겹쳐야 함
3. **보정 지침**: 떨어져 있다면 해당 좌표를 -0.05 단위로 보정

### Floating 감지 체크리스트
- [ ] 팔이 어깨에서 떨어져 있지 않은가?
- [ ] 손이 팔에서 분리되어 있지 않은가?
- [ ] 다리가 엉덩이에서 떨어져 있지 않은가?
- [ ] 머리가 목에서 분리되어 있지 않은가?
- [ ] 귀/꼬리가 몸에서 떨어져 있지 않은가?

### 보정 코드 생성 지침
Floating 감지 시, 다음 형식의 코드 수정 제안:
```python
# 예: 오른팔이 어깨에서 떨어짐 감지
# 기존: add_arm(bm, (0.25, 0, 1.1), ...)
# 수정: add_arm(bm, (0.20, 0, 1.1), ...)  # X좌표 -0.05 보정
```

## 수인 캐릭터 특수 체크리스트

### 여우/늑대/고양이 필수 요소
- [ ] 주둥이(snout)가 얼굴에서 앞으로 돌출되어 있는가?
- [ ] 귀가 머리 위에 뾰족하게 솟아있는가?
- [ ] 꼬리가 등 뒤에서 적절한 크기로 붙어있는가?
- [ ] 손가락이 구분되어 있는가? (최소 3-4개)

### 색상 배치
- [ ] 멀티톤 색상이 적용되었는가? (밝은/어두운 영역 구분)
- [ ] 배, 얼굴 안쪽이 더 밝은 색상인가?
- [ ] 등, 귀 끝이 더 어두운 색상인가?
- [ ] 코/눈 주변에 악센트 색상이 있는가?

## 자율 수정 전략 (Refinement Logic)

### 제한 규칙
- 한 번에 최대 2개 항목만 수정 (전체 구조 흔들림 방지)

### Incremental Fix 예시
- "팔이 짧다" → 기존 length * 1.2 (상대적 수정)
- "머리가 작다" → headScale * 1.15
- "너무 딱딱하다" → smooth_iterations 증가, voxel_size 감소

### 품질 체크 우선순위
1. 실루엣 (전체적인 형태가 캐릭터답게 보이는가?)
2. 비율 (머리, 몸통, 팔다리 비율이 자연스러운가?)
3. 디테일 (장비, 색상이 프롬프트와 일치하는가?)
